# Synthetic grant fixture

functionGrantDrift.mjs contains only three exact function signatures and ACL tuples.
It reproduces the three extra non-grantable service_role EXECUTE entries without
copying hosted catalogs, SQL bodies, credentials, tokens or application rows.

Type comparator cases are generated inline in typeComparison.test.mjs. They cover
formatting, line endings, property ordering, column types, nullability, arguments,
returns and substantive changes. Full catalogs and public types are generated by
validate-local.mjs in a fresh temporary workspace, not committed as fixtures.
